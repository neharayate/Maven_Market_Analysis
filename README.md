Maven Market Sales Analysis Dashboard
## Dashboard Screenshot
Project Overview
-This project focuses on analyzing Maven Market sales performance using Power BI.The dashboard provieds using insights into sales transactions, profit, returns, product brands, stores, and revenue trends.
Tools & Technologies Used:
-Power BI
-Power Query
-DAX
-Data Visualizations
Key Features:
-Current Month Transactions
-Current Month Profit
-Current Month Returns
-Goal & Actual Perfornmance
-Product Brand-wise Sales Analysis
-Profit Margin and Return Rate Analysis
-Weekly Revenue Trend
-Revenue vs Target Analysis
Dashboard Insights:
-Analyzed transaction Performance and monthly profit.
-Compared actual performance with business goals.
-Identified product brand-wise profit margins and return rates.
-Tracked weekly revenue trends.
Conclusion:
This Dashboard help understand business performance through interactive visualizations and KPIs. IT supports better decision- making by providing insights into sales, profit, returns, and revenue trnds.
